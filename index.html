🐻‍❄️

Panel de Comandos

Directorio completo de utilidades de moderación y administración.

Sanciones y Advertencias
  • /warn
    Advertir a un usuario.
  • /warnings
    Consultar las advertencias de un usuario.
  • /unwarn
    Eliminar una advertencia.
  • /clearwarnings
    Eliminar todas las advertencias de un usuario.
  • /kick
    Expulsar a un usuario del servidor.
  • /ban
    Bloquear a un usuario del servidor.
  • /unban
    Retirar el bloqueo de un usuario.
  • /softban
    Expulsar y eliminar mensajes recientes (24h).
  • /timeout
    Restringir temporalmente la interacción.
  • /untimeout
    Retirar el timeout de un usuario.
Canales, Roles y Utilidades
  • /purge
    Eliminar una cantidad determinada de mensajes.
  • /slowmode
    Configurar el intervalo entre mensajes de un canal.
  • /lock / unlock
    Bloquear o desbloquear un canal de texto.
  • /hide / unhide
    Ocultar o restaurar la visibilidad de un canal.
  • /nick
    Cambiar el apodo de un usuario.
  • /role add / remove
    Asignar o retirar un rol a un usuario.
  • /massrole
    Asignar o retirar rol a varios usuarios autorizados.
  • /deafen / undeafen
    Silenciar audio de un usuario en canal de voz.
  • /move
    Mover un usuario a otro canal de voz.
  • /disconnect
    Desconectar a un usuario de un canal de voz.
Sistema de Automod
  • /automod
    Configurar el sistema de automoderación.
  • /automod enable / disable
    Activar o desactivar el automod.
  • /automod words
    Gestionar palabras prohibidas.
  • /automod links
    Configurar la detección de enlaces.
  • /automod spam
    Configurar la detección de spam.
  • /automod mentions
    Configurar límites de menciones.
  • /automod caps
    Configurar límites de mayúsculas.
  • /automod invites
    Gestionar invitaciones de Discord.
  • /automod exemptions
    Configurar excepciones por usuario/rol/canal.
  • /automod logs
    Configurar dónde se registran las detecciones.
